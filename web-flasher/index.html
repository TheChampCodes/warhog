Piglet Wardriver skon's fork

Web Flasher — unofficial fork · flash firmware over USB, no IDE

Before you start

Chrome or Edge (desktop) Data USB cable Plugged in directly, no hub No port? install CP210x / CH343 driver

Pick your board, hit Install, and choose the serial port when prompted. Images are built automatically from olosnoks/piglet.

Boards

Freenove S3 CYD

ESP32-S316 MBHAM UI4

2.4 GHz scanning, GPS, SD logging, 2.8″ touch display. The main CYD build.

Open in Chrome or Edge to flash.
Download .bin manifest
Flash manually 
esptool --chip esp32s3 write-flash 0x0 \
  freenove-s3-cyd-ham-ui4.bin

Official Piglet — XIAO C5

ESP32-C58 MBGPSdual-band

The official Piglet firmware — GPS, SD, WiGLE logging, mesh. Dual-band 5 GHz. Browser flashing is unreliable on the C5 — see note.

Open in Chrome or Edge to flash.
Download .bin manifest
C5 note — use --no-stub if the browser fails 
# The C5 USB-Serial/JTAG drops
# when the stub loads, and the
# browser can't skip it. Flash
# from a terminal instead:
esptool --chip esp32c5 \
  --no-stub write-flash \
  0x0 xiao_c5.bin
