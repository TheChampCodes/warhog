Piglet Web Flasher

open ESP32 wardriving firmware

Plug the board into this computer over USB, pick it below, and Install flashes it straight from the browser — no toolchain, no IDE. Firmware images are built automatically from olosnoks/piglet.

Requirements: desktop Chrome or Edge (Web Serial — Firefox and Safari won't work), a data USB cable, and the board connected directly (not through a hub). If no port appears, install the CP210x / CH343 USB-serial driver for your board.

XIAO ESP32-C5

ESP32-C58 MBdual-band

5 GHz-capable node board. Browser flashing is unreliable on the C5 — see note.

Open in Chrome or Edge to flash.
Download .bin ·manifest
C5 note — use --no-stub if the browser fails 
# The C5 USB-Serial/JTAG drops
# when the stub loads, and the
# browser can't skip it. Flash
# from a terminal instead:
esptool --chip esp32c5 --no-stub \
  write-flash 0x0 xiao_c5.bin
